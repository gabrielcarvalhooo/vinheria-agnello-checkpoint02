# Vinheria Agnello
## Descrição 
O projeto consiste no desenvolvimento de um sistema de cadastro e avaliação de estoque de vinhos da Vinheria Agnello. Nesta segunda etapa, o sistema será aprimorado para permitir o cadastro de múltiplos vinhos em sequência, além de realizar análises das informações registradas.

A aplicação contará com funcionalidades para validar os dados informados, identificar vinhos com estoque baixo, classificar os vinhos de acordo com sua safra e identificar o vinho mais antigo cadastrado. Ao final, será apresentado um resumo com a quantidade de cadastros realizados e os resultados das análises.

O projeto utiliza JavaScript para praticar conceitos de funções, reutilização de código, escopo de variáveis e estruturas de repetição, dando continuidade ao trabalho desenvolvido no primeiro checkpoint.
